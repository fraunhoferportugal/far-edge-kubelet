# End-to-End (E2E) testing
This directory will host `far-edge-kubelet` E2E tests. Those tests assert the behaviour of the `far-edge-kubelet` in the complete FITA stack. Tests are done from a user-level flow point of view. In the context of the `far-edge-kubelet`, this includes changes introduced in the system by a user, such as adding and removing devices or handling device failures.
